DO NOT use a basic Bootstrap-style restaurant template.

DO NOT make it look like a simple WordPress restaurant website.

## Development

Run the development server locally:

```sh
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```sh
bun run build
bun run start
```
